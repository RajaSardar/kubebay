# Lens (Mirantis Lens K8S IDE) vs Kubebay F41-F78

Researched 2026-11-12. Primary sources only: docs.lenshq.io (sitemap fetched and read in full; ~240 URLs, all /k8slens/ pages), lenshq.io/pricing, lenshq.io, docs release notes (2026-09-18, 10-05, 10-12, 10-26, 11-09 releases; control-center post).
Method note: WebFetch uses a small summariser. Every NOT-DOCUMENTED below means "the page where it would naturally appear, plus the sitemap, has no such feature". It does NOT mean Lens lacks it: the docs have no search, and I could not read the app. Phrase any public claim as "Lens's docs do not describe X", never "Lens lacks X".

Sitemap check (applies to every NOT-DOCUMENTED row): the sitemap has no page named topology, upgrade-readiness/deprecations, spof/resilience, rbac-explorer, access-review, audit-log (K8S IDE; only lens-agents/platform-admin/audit-trail, a different product), keda, karpenter, network-policy builder/matrix. Navigator page (https://docs.lenshq.io/k8slens/using-lens/navigator/) lists no Topology/Security/Autoscaling/KEDA/Karpenter/Audit entries.

Plan note: pricing page (https://lenshq.io/pricing, 2026-11-12) lists Personal free; Plus: "Ask AI", "GitOps with Flux or Argo CD", "Security Center (CVE reporting)"; Pro: "Built-in MCP Server"; Enterprise: "Offline activation & air-gapped mode", SSO/SCIM, "Audit logs". Docs premium-features page says "Premium features are included with Plus, Pro, and Enterprise" and lists Cost Monitoring, Security Center, Ask AI, MCP.

## Facts for F72-F78 in one place
- Platforms: macOS 13+, Windows 10 22H2+, Ubuntu 22.04+, Fedora 41+, RHEL 9+, CentOS Stream 9; min 1 GB RAM.
- Network allowlist for restricted environments: api.k8slens.dev, downloads.k8slens.dev (install page).
- In-cluster web app: none documented; Teamwork/Spaces = desktop sharing via a relay pod.
- Account: Lens ID required to activate (FAQ). Personal free only if org revenue/funding under $10M (FAQ).
- Air-gapped: Enterprise (pricing, offline-activation page); the air-gapped mode page says "premium subscription".

## Weakest findings
1. F75 licence: summariser output conflicted between two fetches ("open source on GitHub" vs no licence text). Verify at github.com/lensapp/lens and the Lens EULA before saying anything.
2. F75 telemetry default: the Preferences page confirms a Telemetry section with toggles, but I did not verify whether it defaults on. Avoid claiming "Lens phones home" without checking.
3. F70 plan: pricing says MCP is Pro, docs getting-started says "Plus, Pro, or Enterprise". Cite neither as the lowest plan until reconciled.
4. F44/F43/F45 Helm: the releases page is thin; the details panel contents and live-update behaviour are simply unspecified, so Lens may do more than documented. Only "UNCLEAR" is safe.
5. F61/F64 Security Center: checks come from Trivy-Operator reports and the docs do not list which. Lens may surface some of Kubebay's RBAC and workload findings. F71 is also soft: the Enterprise "Audit logs" is on pricing with no K8S IDE doc to say what it records.
