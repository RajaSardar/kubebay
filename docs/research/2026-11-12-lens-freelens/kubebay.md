# Kubebay feature audit (F01-F78)

Audited read-only against <repo> at HEAD 26e872a (main, 2026-11-12).
Current released app version: 0.7.0 (desktop/src-tauri/tauri.conf.json:4; tag v0.7.0 = 2026-10-30, GitHub release published 2026-10-31).

How "UNRELEASED" was decided: CHANGELOG.md is NOT a reliable guide. It has only `[Unreleased]` and `[0.1.3]` sections, so almost everything shipped in v0.2-v0.7 is still listed under `[Unreleased]`. I used git instead: a feature is UNRELEASED only if it is absent from the `v0.7.0` tag and arrived in one of the 28 commits `v0.7.0..HEAD`. Everything else I treat as shipped in v0.7.0 or earlier (checked with `git grep ... v0.7.0`).
Commits after v0.7.0 that touch the inventory: e7b62e8 (resizable cluster columns), 44394ff (star CRD / API group), 4674a17 (KEDA Paused, search, All), c777ba1 (copy-name button in drawer header), dd324d8 (Pod IP(s)/Host IP(s)), 6acd06a (CRD owners in Owned-by), c094e7a (icon colour keeps short name), 145c6ce (pod delete dialog), ba6927a (truncate long cluster name).

Test conventions: web tests are under web/apps/shell/src/{components,lib,pages}/__tests__ (some beside the file); engine tests are *_test.go beside code; e2e is e2e/tests/golden-path.spec.ts and dra.spec.ts.
"Shell" below = web/apps/shell/src. "Engine" = engine/internal.

Tally: SHIPPED 54, CODE-ONLY 6, PARTIAL 13, UNRELEASED 5 (all "part": the rest of the line shipped), DOCS-ONLY 0, NOT-FOUND 0.
